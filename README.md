# 林小满个人接口

一个面向 AstrBot `>=4.28.2` 的林小满稳定能力适配插件。

目前包含两个独立能力：

1. Photo Capability：`send_xiaoman_photo()`。
2. Voice Performance Guidance：在主 LLM 请求前追加稳定的林小满 MiMo 表演规则，让回复可在自然需要时包含隐藏的表演标签。

它注册无参数工具：

```text
send_xiaoman_photo()
```

该工具仅供已经依据人格和对话上下文决定发送照片的上层 LLM 调用。用户提出照片请求本身不构成调用条件。

语音表演规则不调用额外模型、不改写人格或 TTS 配置；它只提供稳定的格式与使用原则。实际的标签处理、语音合成和展示文字清理仍由现有 TTS 插件负责。

## 依赖与行为

照片能力需要已启用并已注册 `gallery_send` 工具的 Airi Gallery v2.11.15。

语音指导只在公开的 `tts_speak` Function Tool 已注册时注入。如果 TTS 插件缺失、`tts_speak` 被关闭或工具查询失败，本插件会跳过语音指导，避免在没有语音清理链路时让隐藏标签污染普通聊天。

- 照片工具始终以固定目标发送一张林小满照片。
- 目标工具不可用或调用抛出异常时，返回 `PHOTO_SEND_FAILED`。
- 仅在委托工具明确确认已发送一张目标照片时返回 `PHOTO_SENT`；其他普通返回同样返回 `PHOTO_SEND_FAILED`。
- 不会选择其他分类，也不会实现图片存储、随机选择或发送逻辑。
- 不负责 TTS 合成，不修改 TTS 插件，不决定是否发送语音，不负责语音概率或 VoiceClone。
- 不负责人格、记忆、好感度或其他关系判断。
- 语音指导使用固定 system prompt，内容不随每轮对话动态变化。

## MiMo 表演标签配置

当前接口只指导主 LLM 使用以下固定标签：

```text
语速稍快，连续说，停顿很短
轻笑
心虚
委屈
不耐烦
疲惫
撒娇
气声
鼻音
稍慢，语气放软
放慢一点，重点说
```

其中：

- `（语速稍快，连续说，停顿很短）` 是当前实机验证效果最好的普通聊天基础节奏标签。
- 普通短回复通常只使用基础节奏标签。
- 确实存在局部语气变化时，最多再增加一个局部标签。
- `（稍慢，语气放软）` 和 `（放慢一点，重点说）` 只用于局部，不应把整段都拖慢。

**重要：** 上述每一个会被主 LLM 使用的标签，都必须同时存在于 TTS Emotion Router 的“表演标签列表”白名单中。未加入 TTS 白名单的自定义括号文本不会被保证隐藏或透传给 MiMo。

推荐普通聊天：

```text
（语速稍快，连续说，停顿很短）你还真信了啊？笨死了，行啦逗你的
```

需要局部收软：

```text
（语速稍快，连续说，停顿很短）你还真信了啊？笨死了，（稍慢，语气放软）行啦，逗你的
```

## 安装

在 AstrBot 插件页安装本仓库版本，或将本目录放入 AstrBot 插件目录后重启/重载插件。

照片能力要求 Airi Gallery 的 `gallery_send` 可用。

语音指导要求 TTS Emotion Router 的 LLM 函数工具 `tts_speak` 已开启，并确保上面的表演标签已经加入其白名单。

## 开发验证

本仓库包含 GitHub Actions 自动测试。每次 push 或 pull request 会自动运行 Python 单元测试与语法编译检查。

本地也可以运行：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q main.py services tools tests
```
